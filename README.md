# Formula 1 Performance Intelligence Dashboard

## Project Overview
Interactive Power BI dashboard for analyzing Formula 1 performance data from 2020–2024.

## Features
- Driver Performance Analysis
- Constructor Performance Analysis
- Race Analysis
- KPI Metrics
- Interactive Filters and Slicers

## Tools Used
- Power BI
- DAX
- Power Query
- Excel
- ### Formula 1 Performance Intelligence Dashboard | Power BI, DAX, Power Query, SQL

* Developed an interactive Power BI dashboard to analyze Formula 1 driver, constructor, and race performance across the 2020–2024 seasons.
* Performed data cleaning, transformation, and preparation using Power Query to create analysis-ready datasets.
* Built DAX measures and KPIs to evaluate driver performance, constructor standings, race results, points, and season-wise trends.
* Designed interactive visualizations, slicers, and filters to enable users to explore performance across seasons, drivers, constructors, and races.
* Used SQL-based analytical queries to derive rankings, aggregate performance metrics, and season-over-season insights from structured race data.
* Applied data modeling and visualization best practices to convert complex race-level data into intuitive business-style performance insights.
